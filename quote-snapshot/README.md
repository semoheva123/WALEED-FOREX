# خدمة تجريبية لجلب أسعار TradingView عند الطلب

تحذير: TradingView تحظر جمع بياناتها آليًا بما في ذلك السكربتات؛ استخدام هذه الخدمة قد يخالف الشروط ويؤدي للحظر. لم يتم نشرها. إعادة عرض أو توزيع البيانات في صور قد تستلزم حقوقًا إضافية. لا يوجد ضمان بيانات مباشرة أو كاملة.

هذه تجربة بلا تسجيل دخول أو تجاوز حماية. تفتح الخدمة الموقع وتستخدم Playwright لقراءة نافذة الودجت عند كل طلب. فهي لا تعمل على استضافة ملفات ثابتة وحدها وتحتاج خادمًا يشغّل Node وChromium. لا تشغّلها من جهاز المستخدم أو تضع عنوان localhost في إعداد المتصفح.

التثبيت: `npm install` ثم `npx playwright install --with-deps chromium` (يتطلب Linux وتبعياته). يشغّل التطبيق: `SITE_URL=https://validvx.com/ HOST=127.0.0.1 PORT=8002 node server.js`. يجب أن يكون الموقع منشورًا ويحتوي واجهة اختيار الفئة الحالية. ثم اضبط خادم HTTPS أمامي لتحويل المسار `/api/quotes` إلى الخادم الداخلي. على الخادم ذاته يطلب المتصفح `/api/quotes` نسبيًا دون كشف مفتاح. أما للنشر على نطاق منفصل فاضبط `ALLOWED_ORIGINS` وأعد إعداد `window.VX_QUOTE_API` إلى عنوان HTTPS مناسب؛ راجع أمن الوصول ومعدل الطلبات قبل الإنتاج. SITE_URL متغير موثوق للخادم وحده، لا تقبل URL من الزوار.

مثال فحص محلي: `curl 'http://127.0.0.1:8002/api/quotes?category=forex'`. يسمح للخادم بطلب واحد متزامن وتهدئة خمس ثوان لكل IP، لكن هذا ليس حماية إنتاجية أو رخصة استخدام. أوقف الخدمة فورًا إذا رفض المزود الاتصال. وقت الالتقاط هو وقت القراءة وليس وقت تحديث كل سعر. بعض الأسعار قد تكون غير متاحة فتظهر كذلك. يجب التحقق يدويًا من الرموز وأوقات التأخر والحقوق قبل أي استخدام.
